# Маршрутизация и экономность

Модель выбирается в интерфейсе редактора. Автоматического API-переключения и платных вызовов в CLI нет. Сначала используем сохранённые материалы.

| Задача | Достаточный инструмент | Условие смены маршрута |
|---|---|---|
| Память | agent.py search --query, rg, depends_on | Не найдено: синонимы и связанные ID; семантический поиск не реализован |
| Доли в CSV | `tools/analyze.py`, контракт сравнения | Дубли, несовместимость или открытые окна: исправить основание перед сравнением |
| Деньги и нагрузка | `tools/case_calculator.py` по запросу | Сверить валюту, период и ссылки на исходные числа. Примеры в `docs/analysis-tools.md` |
| Документ | Сохранённая заметка/индекс, выбранные фрагменты | Новый PDF/DOCX/XLSX: ingest по запросу; PDF optional pypdf6.21.4; при отказе разрешённый текстовый экспорт. Подробности docs/import.md |
| Актуальные функции | Веб-поиск и открытие первоисточника | Противоречие: независимый источник; справка не доказывает спрос |
| Проверка полей | Самая доступная модель с достаточным качеством | Смешение факта и гипотезы: основная модель и сверка основания |
| Стратегия | Основная рассуждающая модель | Существенный риск: человек выбирает по готовому предложению |
| Параллельное чтение | До двух read-only помощников, если среда поддерживает | Только основной агент пишет; помощник возвращает URL, локатор и ограничения |

В этой доработке использованы Codex (среда сообщает GPT-6; модель gpt-6.1-sol подтверждена metadata; режим скорости и фактический счёт неизвестны), read-only помощники той же среды, web и Python. Каталог моделей и цены не зашиты. Jev и отдельный классификатор не подключены.

Стоп: вопросы выбора закрыты, лимит достигнут либо следующее чтение не различает варианты. Для public-case наличие альтернатив установлено; новые обзоры функций не заменят сведения о проблеме команды. Синтетические респонденты не доказывают спрос.

Значимые операции писать через log: модель, инструмент, секунды, повторы, цена/валюта и помощь человека. Неизвестное — unknown/null. Расходы на продукт и расходы на работу агента учитывать отдельно.

Обычный ответ: краткая карточка, имеющиеся основания и конкретное действие. Не запускать полную приёмку, повторный импорт или помощников на каждый вопрос. Дополнительная проверка нужна при новом существенном основании, противоречии, численном решении или риске. Полноту стратегии и контроль источников сохранять в обоих маршрутах. Для новичка объяснять термин при первом появлении и давать одно выполнимое действие; не уменьшать доказательность ради краткости.

После ingest источник indexed ещё не прочитан. Сначала excerpt с точным местом, затем source-read только для реально прочитанного диапазона. Числа формул/кэшей не смешивать. Проверки SHA в briefing и checkpoint обязательны; ради скорости их не отключать. PERF-1 измеряет только техническую задержку, не заменяет бизнес-метрики и BENCH-2.
