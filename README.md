# Стратег Фабрики продуктов

Агент помогает решить, что делать с продуктом дальше. Вы даёте ему вопрос и материалы, а он сравнивает варианты, показывает расчёты и объясняет свой выбор. После перерыва можно открыть новый чат и продолжить с сохранённого места.

## Что в примере

Команда ведёт регулярные задачи в таблице и думает, нужен ли ей свой трекер. Агент сравнил четыре варианта. Когда выяснилось, что готовый сервис уже умеет показывать будущие повторы, аргумент за свою разработку стал слабее. Итоговое предложение — попробовать улучшенный шаблон две недели. Запуск пилота пока открыт.

## Как запустить

Откройте папку в редакторе с ИИ. Для расчётов и сохранения нужен Python 3.10+. Готовый запрос и пример продолжения находятся в [START.md](START.md).

```sh
python tools/replay_demo.py
```

Команда создаст локальный учебный проект и покажет его короткую карточку. Чтобы отдельно проверить сохранение, продолжение и пересмотр, запустите `python tools/replay_demo.py --check`.

Материалы, правила и выводы хранятся в обычных файлах. Агент сверяет таблицы перед расчётом и показывает, сколько денег и времени нужно на каждый шаг. Решение о расходах и запуске принимает человек.
