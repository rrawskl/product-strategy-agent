# Время и расходы

Локальные команды проект запускает без отдельного платного API. Редактор предоставляет модель по своему тарифу. Полное время живой демонстрации и её списания предстоит замерить при записи.

В историческом сравнении на трёх учебных задачах медиана времени составляла 53,77 секунды для обычного запроса и 51,91 секунды для файлового агента. Медиана расчётного ресурса составляла 1,223 и 1,117 Standard-кредита соответственно. В измерение вошли ожидание и инструменты. [Сравнение](benchmark.md)

Снимок разработки от 9 ноября охватывал 298,1 минуты с возможными паузами и 630,46 расчётного Standard-кредита. Этот объём включает разработку, ревью, тестирование и исправления. При допущениях 0,04 USD за кредит, 5–15 минут участия по 20 USD в час и резерве 25% получался диапазон 26,89–36,52 USD. Фактический счёт неизвестен. Ставки взяты из таблицы для GPT-6.1 Sol на дату 8 ноября. [Источник ставок](https://learn.chatgpt.com/docs/pricing)

Последний локальный прогон исходного кейса занял 1,76 секунды. В этот интервал вошли команды проверки, сохранения, продолжения и пересмотра. Для повторения из публичного репозитория есть отдельная команда. [Проверка продолжения](checks.md)
