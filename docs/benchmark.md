# Как проверялись ответы

В историческом сравнении использовали три учебные задачи. Агент объяснял изменение возвратов, сравнивал зрелые и незрелые группы и выбирал инструмент с учётом затрат. На каждую задачу получили по два ответа с файловыми правилами и по два с обычным запросом. Всего 12 ответов. Два модельных оценщика читали их без названий условий.

| Задача | Обычный запрос / 10 | Файловый агент / 10 |
|---|---:|---:|
| Возврат и состав каналов | 10,00 | 10,00 |
| Зрелость периода и трекинг | 9,625 | 9,75 |
| Выбор инструмента и затраты | 9,1875 | 9,1875 |
| Среднее | 9,6042 | 9,6458 |

Оценщики не отметили критических ошибок. Они разошлись по двум пунктам рубрики. Три задачи дают ограниченное сравнение. В одном из следующих опытов отдельная повторная проверка моделью заняла больше времени и ресурса, поэтому для ежедневной работы сохранён один основной разбор.

В текущей версии добавлены отдельные тесты CSV и арифметики. Они проверяют известные ошибки и дают воспроизводимые результаты. [Пример входных данных](../evaluation/case.md) · [Как повторить технические проверки](checks.md)
