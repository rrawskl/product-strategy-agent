# Видео работы агента

[Смотреть на Google Диске, 2 мин 50 с](https://drive.google.com/file/d/1Z5obusFZrLMOV7TrBhfQ_CcknUthfV0h/view)

На экране только окно демонстрации. Текст и команды взяты из учебного прогона. Во втором сеансе модель прочитала файлы проекта и восстановила следующий шаг без истории первого.

| Время | Что происходит |
|---|---|
| 0:00 | Запрос руководителя |
| 0:17 | Входные материалы и вопросы агента |
| 0:35 | Что изменилось после проверки открытой справки |
| 0:54 | Четыре варианта и сценарные затраты |
| 1:22 | Продуктовая стратегия |
| 1:46 | Коммуникационная стратегия |
| 2:06 | Сохранение работы и проверка файлов |
| 2:25 | Продолжение в отдельном сеансе |
