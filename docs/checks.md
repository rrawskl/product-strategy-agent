# Как повторить проверки

Из папки проекта выполните команды:

```sh
python tools/check.py
python tools/check_import.py
python tools/check_analysis.py
python tools/check_calculator.py
python tools/replay_demo.py --check
```

Первые четыре команды запускают 37 тестов. Для теста импорта PDF установите пакет из `requirements-import.txt`. Без него этот тест пропускается. Остальные тесты проверяют файлы, память, таблицы и числа на учебных данных.

Последняя команда создаёт временную копию примера, сохраняет предложение, заново читает состояние и показывает, какие выводы зависят от изменившегося источника. Сценарий содержательной работы с моделью можно повторить по инструкции. [Запуск агента](../START.md)
