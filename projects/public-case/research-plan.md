# Исследование, вопросы и стоп-критерий

1. Есть ли подтверждённая проблема команды? Не установлено; исходный сценарий авторский.
2. Какие сценарии должны работать? P1v3 явно задаёт K1–K5 как условия упражнения.
3. Закрывают ли их существующие предложения? Выполнена документальная проверка 15 сочетаний P7 по P2–P4/P6; runtime неизвестен.
4. Доказывает ли необходимость будущих повторений уникальность B? Нет: P6 документирует их в Calendar Pro/Business. H2 остаётся гипотезой.
5. Какая ставка разумнее по авторским допущениям? R2: D для обратимого пилота; C при обязательном K4 и L<33667 руб./год при прочих равных; B требует добавочной пользы сверх разрыва186333 руб. P9 — сценарий, не реальная смета.
6. Как проверить пользу и не навредить? Две недели после выбора, −20% медианы парных недельных затрат обслуживания относительно A, 100% обязательных действий, ноль потерь/дублей; P1/strategy, не проведённый опыт.

Стоп поиска: функции и ограничения, способные отличить варианты, установлены в заявленных границах. Дополнительные общие обзоры не докажут спрос. Следующий шаг — решение человека о конкретном пилоте, проверка доступа и K5. Публичная документация не заменяет наблюдение поведения.
